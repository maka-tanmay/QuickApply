# Icons

Place your extension icons here:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

You can create simple placeholder icons or use a design tool to create branded icons for JobRight AI.

For quick testing, you can use any PNG files with the correct dimensions, or create simple colored squares with text.
