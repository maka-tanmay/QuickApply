# Icon Generation Instructions

## Quick Method (Recommended)

1. **Open `generate-icons.html`** in your browser
   - Double-click the file, or
   - Right-click → Open With → Chrome/Safari

2. **Click "Generate & Download All Icons"**
   - This will download 3 PNG files:
     - `icon16.png`
     - `icon48.png`
     - `icon128.png`

3. **Move the downloaded files** to the `icons/` folder
   - They should be in your Downloads folder
   - Move them to: `/Users/tanmaymaka/Desktop/extension for job application/icons/`

4. **Done!** The extension is ready to load.

## Alternative: Use Any Icons

If you have existing PNG icons:
- Just place them in the `icons/` folder with these exact names:
  - `icon16.png` (16x16 pixels)
  - `icon48.png` (48x48 pixels)
  - `icon128.png` (128x128 pixels)

## What the Icons Look Like

The generated icons feature:
- Purple gradient background (#4F46E5 to #7C3AED)
- White "J" letter in the center
- Clean, modern design
- Proper sizing for Chrome extension

## After Icons Are Ready

1. Load extension in Chrome:
   - Go to `chrome://extensions/`
   - Enable Developer mode
   - Click "Load unpacked"
   - Select the extension folder

2. Test it:
   - Open `test-page.html`
   - Create a profile
   - See the magic happen! ✨
